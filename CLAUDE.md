## Repository Purpose

Personal learning and reference repository focused on data engineering tools (DBT, Git) and course materials. Notes and content are written in Portuguese.

## Structure

- `Comando - GIT.txt` — Git command reference notes (Portuguese)
- `comandos_dbt.xml` — DBT command reference
- `index.html` — HTML template
- `data-engineering-zoomcamp/` — Directory for data engineering course materials (expanding over time)

## Conventions

- File notes and documentation are written in Portuguese.
- There are no build systems, test suites, or linting tools configured. This is a notes/learning repository.
- New course material or topic directories should follow the pattern of `data-engineering-zoomcamp/` — one directory per course or topic area.
